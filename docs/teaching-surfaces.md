# TRACE 교수자 운영 화면

## 역할과 구조

기존 TRACE 색상, 사이드바, 카드, 입력폼, 버튼을 재사용하는 Operate 화면이다.

- 팀별 모니터링: 어느 팀에 개입할지 판단한다. 데스크톱은 팀 표 62% / 선택 상세 38%, 세로 태블릿은 순서대로 쌓는다. 진행률은 평가 점수가 아니다.
- 학생별 평가 지원: 학생의 실제 역할 수행과 이해를 과정증거로 검토한다. 데스크톱은 학생 목록 25% / 상세 75%, 작은 화면은 목록 뒤 상세를 배치한다.

## 데모 동작

24명·6팀의 네트워크 실습 기록을 사용한다. 2팀은 반복 수정, 4팀은 활동 지연, 3팀은 교수자 승인형일 때 개입 제안 대기로 표시한다.
과제 선택, 상태 필터, 팀 선택, 승인·수정 후 승인·거절, 가이던스 초안 저장, 학생 검색 및 학생 선택이 동작한다.
팀원 이름에서 해당 학생 평가로, 학생의 팀 보기에서 해당 팀 모니터링으로 이동한다.
현재 과제의 제목·운영 방식·평가 기준은 과제 설계 상태를 사용한다. 학생별 평가와 피드백은 과제/학생 키로 브라우저에 저장한다.
개인 AI 채팅 원문은 포함하지 않으며, 구조화한 사용 내역과 과정증거만 제공한다. 실제 AI 호출이나 학생에게 메시지 전송은 없다.
AI는 판단 참고 정보만 정리하며 교수자가 평가 항목별 판단을 직접 선택한다. 승인 처리와 가이던스 제안은 현재 화면 세션의 데모 상태이며, 가이던스는 처리 알림으로 확인한다. 영구 저장 대상은 학생별 교수자 평가와 피드백이다.

## 시각 시스템

새 브랜드 토큰 없이 DESIGN.md의 primary, mint-soft, yellow-soft, rose-soft, lavender-soft와 기존 panel/button/field를 사용한다.
상태는 색과 텍스트를 함께 제공하며, 주요 표에는 의미 있는 헤더와 네이티브 입력 요소를 사용한다.
기존 DESIGN.md의 과제 생성 2열 레이아웃 설명은 이전 구현에 관한 기록으로 남아 있으며 이번 화면의 레이아웃 기준으로 사용하지 않는다.
