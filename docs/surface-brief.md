# 과제 생성보드

Mode: Operate. 사용자가 세 단계 구조와 세부 입력항목을 직접 지정했으며 기존 시각 레퍼런스를 유지한다.
THESIS: 교수자가 과제와 AI 지원 방식을 한 흐름으로 설계한다.
OWN-WORLD: 사용자 이미지의 녹색 사이드바, 회백색 바탕, 흰 둥근 패널, 민트 활성 상태.
STORY: 기본 정보/목표 → 요구사항/산출물 → 평가 비율 → AI 운영 방식 → 학생 화면 미리보기 → 생성.
FIRST VIEWPORT: 기존 시안 사이드바와 세 단계 표시, 기본 정보와 목표 입력.
FORM: 두 열 폼과 전체 너비 평가 기준, 두 번째 단계의 운영 탭. 태블릿 세로에서 사이드바는 접힌다.
생성은 브라우저 로컬 저장이며 실제 배포가 아니다. 목표 추천과 과목 기준은 데모 데이터이다. 별도 Learning Evidence 입력 페이지는 없다.

## 두 시나리오의 공통 계약

네트워크 실습과 융합 팀 프로젝트는 동일한 과제 설계 → AI 운영 방식 → 학생 미리보기의 세 단계, 사이드바, 카드, 필드, 검증 규칙을 사용한다. `scenarios.ts`가 과목·과제·목표·평가 기준·실행 예시 데이터를 선택한다. `KnowledgeConnections`로 이전 학기·다른 교과·새 학습 영역을 연결하며 두 시나리오 모두 같은 추가 폼을 사용한다. 과제 저장과 진행 중 수업 스냅샷은 `workspaceKey`로 분리한다. 워크스페이스를 바꿔도 현재 역할·메뉴·단계는 유지하되 저장 데이터는 해당 시나리오에서 읽는다. 별도 융합 전용 생성 화면은 없다.

## 추가된 상호작용
- 번호 표식은 레퍼런스의 민트·로즈·옐로·라벤더 파스텔 박스로 표시한다.
- 상황 유형과 가이던스 옵션은 추가·삭제·선택할 수 있다.
- 산출물 추가와 산출물별 양식 업로드는 별도 동작이다. 양식은 파일당 2MB까지 데모에 첨부하며 다운로드와 임시 저장을 지원한다. 저장 공간 부족 시 오류를 표시한다.
- 개입 수준은 최소/보통/적극 세 단계이며 설명에 질문·탐색·검증 지원 차이를 명시한다. 외부 AI 사용 감지나 별도 개입 시점 선택은 제공하지 않는다.
- 학생 미리보기는 입력한 과제/산출물/평가 기준 및 학습 지원 대화 예시를 표시한다.
- 사이드바는 데스크톱에서도 접고 펼칠 수 있다. 프로필 드롭다운은 교수자 강병준과 학생 유송민의 시연 역할을 전환한다. 워크스페이스 선택과 역할 전환은 공통 `WorkspaceSidebar`를 사용한다.
